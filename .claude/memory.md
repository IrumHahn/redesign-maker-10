> 2026-08-15 인수인계. 이전 세션이 구버전 폴더(`Documents/redesign-wizard`)를 실제 프로젝트로 착각하고 작업한 뒤, 결정사항과 자산을 이 파일로 옮김. **이 폴더(`New project 5`)가 진짜 리디자인 마법사 소스**이며 https://hanirum-redesign-wizard.vercel.app/ 로 배포됨.

## 1. 1.5 버전 프로젝트 목표 (사용자 확정)

- 리디자인 마법사가 좋았다는 사용자 피드백을 받아 **1.5 버전으로 개선 런칭**
- 핵심 가치: **카피/기획 품질** (사용자 피드백의 핵심 이유)
- 최종 결과물: **카피가 합성된 섹션 이미지 ZIP** (섹션 이미지 묶음 다운로드)
- 카피 합성 방식: AI가 이미지에 글자를 그리는 방식(3.0 통이미지)이 아니라 **앱에서 Canvas로 텍스트 합성** (한글 깨짐 없음, 수정 즉시 반영)
- 배포: BYOK(사용자 API Key 입력) 유지

## 2. 고정 철학 (사용자 승인 — 기능 제안 시 이 철학에 어긋나면 지적할 것)

**"가볍고 심플하게. 핵심 결과만 잘 나오게."** — 사용자 왈 "힘을 주고 욕심을 낸 것이 독이 됐다"

- 원샷 블루프린트 설계 + 한국 PDP 정보 공식(체크리스트/베네핏3/근거 3단/CTA 4회) 유지
- 프롬프트는 짧고 템플릿 중심 — 규칙 쌓기 금지
- **지식파일 등록 기능은 1.5에서 폐지** (운영자 플레이북·사용자 지식파일 원문 주입 모두). 검증된 전환 인사이트는 템플릿 규칙 1~2줄로 승격하는 방식으로만 반영. 제품 사실 입력 확장도 1.5 범위에서 제외
- 1.5에서 하지 않는 것: 판매 스타일 선택, 히어로 확장 플로우, 고객 후기 업로드/분석, 통이미지 모드, 어드민/버그리포트

## 3. 1.0 vs 3.0 결과물 차이 분석 (사용자가 "놀라운 인사이트"라고 평가)

피드백: "1.0이 3.0보다 더 상세페이지스러운 결과가 나온다." 원인 5가지:

1. **구조 공식 교체가 최대 원인**: 3.0은 PDP 정보 공식을 StoryBrand 8단계 판매 서사(Hero→Problem→Guide→Plan→Purchase→Success→Failure→Close, "판매 영화처럼")로 교체 → 광고 랜딩처럼 읽힘. 1.0의 고정 정보 공식이 한국 커머스 관습에 맞았음
2. **CTA 제거**: 3.0 통이미지 모드는 마켓플레이스 정책 때문에 CTA 전면 금지 → "팔려는 페이지" 인상 약화. 1.0은 CTA 4회 강제
3. **2단계 생성(히어로→확장)**: 전역 설계 약화, 섹션 간 전환 문장 위주 카피로 정보 밀도 하락
4. **프롬프트 비대화**: 수십 개 강제·금지 규칙이 주의력 희석. 금지 문구 목록이 계속 늘어난 것 자체가 StoryBrand 프레임이 추상 카피를 유도했다는 증거 (원인은 두고 증상만 막음)
5. **통이미지(AI 타이포 렌더링)**: 한글 렌더링 품질 불안정, 섹션별 스타일 분산으로 통일감 저하

⚠️ 주의: 이 분석의 "1.0" 프롬프트는 구버전 프로토타입(`Documents/redesign-wizard/src/services/geminiService.ts`) 기준. **진짜 1.0(이 폴더)의 프롬프트로 재검증 필요.** 3.0 쪽 분석(`Documents/Codex/pdp-maker-30-redesign/lib/pdp-server/pdp.service.ts`)은 유효.

## 4. 지식파일 기능에 대한 결론 (사용자 승인)

- 지시형 지식(전환 이론 일반론) 주입 = 독: 모델이 이미 아는 내용 + 템플릿과 경쟁 + 주의력 희석 → 결과 변수 증가
- 사실형 지식(제품 스펙/인증/수치/금지표현) = 약: 템플릿의 빈칸을 채움
- **그러나 1.5에서는 둘 다 열지 않기로 최종 결정** ("정말 라이트한 버전으로")
- 참고: 이 폴더의 실제 1.0에는 지식파일 등록(RAG 청크) 기능이 이미 있으나 미오픈 상태 — 1.5에서 오픈하지 않음

## 5. 구버전 폴더에서 구현 완료된 1.5 기능 (이식 가능 자산)

위치: `Documents/redesign-wizard`, 브랜치 `feature/wizard-1.5`, 커밋 `16a5876` (baseline `ab56ba4`)

- API Key 버그 수정 (에디터 내 `process.env.API_KEY` → 사용자 키 props 전달)
- 카피 인라인 편집 컴포넌트: `src/components/EditableText.tsx`

- 프롬프트 사실 안전장치 4줄 (날조 금지 + 제작자용 설명문 금지) — 이 이상 규칙 추가 금지
- **Canvas 텍스트 합성 렌더러**: `src/services/overlayRenderer.ts` (히어로형/정보형/CTA형 템플릿 3종, 톤 프리셋 8종, Pretendard, 자동 템플릿 추론 `inferTemplate`)
- ZIP 내보내기: `src/services/exportZip.ts` (`01_히어로.png` 순번, jszip)
- 블루프린트 마크다운 복사: `src/services/blueprintMarkdown.ts`
- 세션 복원: `src/services/sessionStore.ts` (localStorage, 이미지 제외 직렬화)
- vitest 테스트 14개 (순수 로직: 템플릿 추론/톤/파일명/마크다운/직렬화)
- 설계·계획 문서는 이 폴더 `docs/handoff-from-old-folder/`에 복사됨
