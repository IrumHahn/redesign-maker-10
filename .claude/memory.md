## 2. 고정 철학 (사용자 승인 — 기능 제안 시 이 철학에 어긋나면 지적할 것)

**"가볍고 심플하게. 핵심 결과만 잘 나오게."** — 사용자 왈 "힘을 주고 욕심을 낸 것이 독이 됐다"

- 원샷 블루프린트 설계 + 한국 PDP 정보 공식(체크리스트/베네핏3/근거 3단/CTA 4회) 유지
- 프롬프트는 짧고 템플릿 중심 — 규칙 쌓기 금지
- **지식파일 등록 기능은 1.5에서 폐지** (운영자 플레이북·사용자 지식파일 원문 주입 모두). 검증된 전환 인사이트는 템플릿 규칙 1~2줄로 승격하는 방식으로만 반영. 제품 사실 입력 확장도 1.5 범위에서 제외
- 1.5에서 하지 않는 것: 판매 스타일 선택, 히어로 확장 플로우, 고객 후기 업로드/분석, 통이미지 모드, 어드민/버그리포트

## 3. 1.0 vs 3.0 결과물 차이 분석 (사용자가 "놀라운 인사이트"라고 평가)

피드백: "1.0이 3.0보다 더 상세페이지스러운 결과가 나온다." 원인 5가지:

1. **구조 공식 교체가 최대 원인**: 3.0은 PDP 정보 공식을 StoryBrand 8단계 판매 서사(Hero→Problem→Guide→Plan→Purchase→Success→Failure→Close, "판매 영화처럼")로 교체 → 광고 랜딩처럼 읽힘. 1.0의 고정 정보 공식이 한국 커머스 관습에 맞았음
2. **CTA 제거**: 3.0 통이미지 모드는 마켓플레이스 정책 때문에 CTA 전면 금지 → "팔려는 페이지" 인상 약화. 1.0은 CTA 4회 강제
3. **2단계 생성(히어로→확장)**: 전역 설계 약화, 섹션 간 전환 문장 위주 카피로 정보 밀도 하락
4. **프롬프트 비대화**: 수십 개 강제·금지 규칙이 주의력 희석. 금지 문구 목록이 계속 늘어난 것 자체가 StoryBrand 프레임이 추상 카피를 유도했다는 증거 (원인은 두고 증상만 막음)
5. **통이미지(AI 타이포 렌더링)**: 한글 렌더링 품질 불안정, 섹션별 스타일 분산으로 통일감 저하

### 재검증 결과 (2026-08-15, 진짜 1.0 = 이 폴더 `src/app/api/generate/route.ts` 기준)

- ✅ **원인 1(구조 공식) 유효**: 진짜 1.0은 고정 섹션 템플릿 S1~S10(`sectionTemplates()`)이 PDP 정보 공식 그대로 — S2 체크리스트, S3 베네핏3, S5 근거 3단, CTA는 S1/S8/S10에 강제. 최대 원인 맞음
- ✅ **원인 2(CTA) 유효**: 템플릿에 CTA가 명시적으로 포함됨
- ⚠️ **원인 3(2단계 생성) 약화**: 진짜 1.0도 히어로 1장 → `generateRemainingSections()` 2단계 플로우가 있음. 단 분석은 원샷 1회 + 전 섹션 템플릿이 전역 고정이라 3.0처럼 단계별 재도출로 설계가 흔들리지 않음. 핵심은 "전역 템플릿 고정"이지 "1회 생성"이 아님
- ✅ **원인 4(프롬프트 크기) 유효**: 진짜 1.0 섹션 프롬프트는 ~15줄(규칙 6줄), 분석 프롬프트 ~10줄로 짧음
- ❌ **원인 5(통이미지) 무효**: **진짜 1.0도 통이미지 방식** — gpt-image-2/나노바나나가 한글 카피를 이미지에 직접 렌더링. 사용자가 좋아한 1.0 결과물 자체가 AI 타이포 렌더링 결과. 카피 텍스트는 이미지에만 존재하고 구조화된 카피 데이터는 클라이언트에 없음
- **1.5 함의**: "Canvas 합성" 결정은 구버전 프로토타입을 1.0으로 착각한 전제에서 나옴. Canvas의 근거(한글 깨짐 없음, 수정 즉시 반영)는 여전히 유효하나, 결과물 스타일이 검증된 1.0 통이미지와 달라지는 리스크 있음 (AI가 레이아웃 다양성까지 그려주던 것을 앱 템플릿 3종이 대체) → 사용자 재확인 필요

## 4. 지식파일 기능에 대한 결론 (사용자 승인)

- 지시형 지식(전환 이론 일반론) 주입 = 독: 모델이 이미 아는 내용 + 템플릿과 경쟁 + 주의력 희석 → 결과 변수 증가
- 사실형 지식(제품 스펙/인증/수치/금지표현) = 약: 템플릿의 빈칸을 채움
- **그러나 1.5에서는 둘 다 열지 않기로 최종 결정** ("정말 라이트한 버전으로")
- 참고: 이 폴더의 실제 1.0에는 지식파일 등록(RAG 청크) 기능이 이미 있으나 미오픈 상태 — 1.5에서 오픈하지 않음
