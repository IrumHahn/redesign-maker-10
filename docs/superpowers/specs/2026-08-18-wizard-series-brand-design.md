# 한이룸 마법사 시리즈 로고/디자인 가이드 — 설계 스펙 (2026-08-18)

## 목적
마법사 시리즈 앱들의 로고·파비콘이 제각각인 상태를 실행학교(오렌지 R) 가이드와 같은 문법으로 통일한다.
관계: **형제 브랜드** — 같은 규칙(단색 사각형 + 한 글자 레터마크), 색과 글자만 다름.

## 마스터 마크
- 에메랄드 `#34d399` 정사각형, 코너 반경 = 변의 22%
- 중앙 차콜 `#171a1f` "W" 레터마크, SVG 패스로 고정(폰트 비의존)
- 요소 2개(배경 + W). 별·문서 등 부가 픽토그램 없음
- 코드: R = 실행학교, W = 마법사 시리즈

## 컬러
| 이름 | HEX | 용도 |
|---|---|---|
| Wizard Emerald | #34d399 | 마크 |
| Ink | #171a1f | W, 텍스트 |
| Off-white | #f7f8f5 | 반전 배경 |
| Lime | #a3e635 | 보조 강조(제한) |

반전형: 차콜 배경에서도 에메랄드 사각형 유지. 단색 필요 시 차콜 사각형 + 오프화이트 W.

## 타이포
Pretendard 600–900(워드마크·제목), SF Mono 대문자(라벨·버전 태그).

## 변형
마스터 마크 / 가로 락업(마크 + 워드마크 2줄 "한이룸의 ○○ 마법사 1.5") / 파비콘(마크 단독).
시리즈 앱 구분은 워드마크 텍스트로만. 색·글자 변주 금지.

## 규칙
- 여백: 마크 높이 1/4. 최소 디지털 24px, 인쇄 8mm
- 금지: 비율 왜곡, 회전, 색 변경, 그림자/글로우, 저대비 배경, 테두리, W 교체
